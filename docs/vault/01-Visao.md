# Visão

Plugin Claude Code para reduzir saídas verbosas entregues ao contexto, preservando o original local quando a compactação ocorre, conforme comportamento a verificar no código.

Prioridade: confiança operacional, instalação reproduzível, documentação honesta e releases rastreáveis.

Invariantes a verificar e preservar: fail-open; ativação por projeto; original salvo antes da substituição; bypass; proteção de saídas estruturadas. Não converter hipóteses da revisão anterior em garantias.

Economia de caracteres é diferente de tokens faturados e de quota de assinatura.
