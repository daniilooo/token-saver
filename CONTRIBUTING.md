# Contribuição

Use Node 20+ e `npm test`. Adicione fixtures anonimizadas e teste erros no meio, stderr, conteúdo estruturado, concorrência, configuração inválida e falha de gravação. Preserve o resultado original quando o formato for desconhecido. Não declare sucesso com base no texto que sobrou do filtro.

Antes de distribuir uma versão, valide manifests com Claude Code e execute o piloto em cada plataforma. Descreva limites reais no README. Atualize CHANGELOG e versões. Não inclua logs de projetos ou credenciais.
